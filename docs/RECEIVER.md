# 受信ツールの動作

## 再開とゼロからの受信

通常の「受信開始」は、保存先にある同じ送信セッションのデータを読み込みます。保存済みのフレームはCRCを確認して再利用し、欠落分を今回の映像から補完します。PS2の送信セッションと密度が同じなら、ツールを閉じて開き直しても再開できます。

画面の「受信済み」は保存済みと今回の新規受信の合計です。「保存済みから再開」は今回の開始時に読み込んだバイト数とフレーム数、「今回の新規受信」は開始後に初めて追加した分です。重複フレームは新規受信に加算しません。直近の受信範囲には、新規取得か取得済みの再受信かを表示します。

前回すべて受信したセッションなら、新しい正常フレームを1つ読み取った後、保存済みだけで完成を確認することがあります。これは今回すべてのデータを映像から受信したことを意味しません。保存済みの全体CRCを再確認して、完成したことを表示します。

「今回の平均速度」は、今回新しく追加した正常データのバイト数を受信セット開始からの経過時間で割った値です。単位はkB/sで、1 kBは1,000バイトです。保存済みの読み込み、重複フレーム、CRCで拒否したデータは受信量に含めません。映像待ちや欠落を待つ時間は含めます。密度や送信セッションが変わると計測をやり直し、完成後は速度と経過時間を固定します。録画・PNG入力では再生時間ではなく処理時間に対する速度です。

「全体の受信位置」は先頭を左、末尾を右として、データ全体を最大128区画に分けたマップです。緑は区画内をすべて受信、黄は一部受信、灰は未受信を示します。白枠と位置の百分率は直近に受信したフレームの先頭位置です。これは全体の完成率とは別で、周回や欠落の補完によって前後します。保存済みから再開した区画もマップに反映します。

速度や密度の比較には「ゼロから受信する」をオンにします。受信開始ごとに保存先の `fresh/` 内へ新しいフォルダーを作り、以前の保存済みフレームを使わずに受信します。以前のバックアップや途中データは削除しません。途中で停止した新規受信を再開する場合は、その実際の保存先を指定し、「ゼロから受信する」をオフにします。

## プレビューと停止

「受信開始」を押すとボタンが「受信停止」に切り替わります。受信開始時には前回の画像を消し、新しい映像を待ちます。完成ファイルを保存した後もキャプチャとライブ表示を続け、同じセッションの周回で完成通知を繰り返しません。PS2側で送信対象や密度を変えると、ボタンを押し直さずに次の受信へ進みます。

「受信停止」を押すかツールを閉じると、キャプチャ機器を解放します。取得中は「映像取得中」、停止後は「プレビュー停止」と表示します。停止中の画像は最後に取得した映像で、ライブ表示ではありません。録画やPNG入力では、完成後も入力の末尾まで処理して停止します。

## 保存と送信設定の変更

正常なフレームを随時保存し、すべて揃った後に全体CRCが一致した場合だけ完成ファイルを保存します。既存の完成ファイルは同じ内容なら再利用し、異なる内容なら上書きせずにエラーを表示します。

送信セッションや密度が変わると、別の受信セットへ切り替わります。異なる密度の途中データは混ぜません。「保存済みから再開」と「今回の新規受信」の表示も、現在の受信セットについての値に切り替わります。

受信フレーム、完成ファイル、録画には元データが含まれます。BIOSを受信した場合は個人のバックアップとして管理してください。
